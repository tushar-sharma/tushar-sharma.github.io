## Roth IRA

What's a Roth IRA? First, let's understand a traditional IRA. It is a retirement account where contributions may be tax-deductible, but withdrawals are taxed. With a Roth IRA, you contribute post-tax money, so qualified withdrawals are tax-free.

For a qualified withdrawal:

1. The Roth IRA must be at least five years old.
2. You must be at least 59½ years old, with some exceptions.

For 2026, the contribution limit is $7,500 per year ($8,600 if you are 50 or older). [Source: IRS](https://www.irs.gov/retirement-plans/plan-participant-employee/retirement-topics-ira-contribution-limits)

For married couples filing jointly, direct contributions phase out between $242K and $252K of MAGI. Above $252K, you may consider a **backdoor Roth IRA**. 

Let's use Schwab as a brokerage account example:

1. Open a traditional IRA. In Schwab, it may appear as a contributory IRA.

2. Transfer cash from a regular brokerage account to the traditional IRA and select 2026 as the contribution year.

3. Open a Roth IRA.

4. Go to **Move Money → Online Transfer**, select the traditional IRA as the source, and choose **Roth conversion**.

A Roth conversion can have tax consequences, especially if you already hold pre-tax IRA funds.

## Solana

Every time you write to Solana, you get a transaction hash (tranx). A tranx by itself doesn't mean it has been published to Solana.

You can use a public RPC endpoint:

```http
POST https://api.devnet.solana.com
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getSignatureStatuses",
  "params": [
    ["{{transactionHash}}"],
    { "searchTransactionHistory": true }
  ]
}
```

It gives the following response:

```json
{
  "jsonrpc": "2.0",
  "result": {
    "context": {
      "apiVersion": "4.4.0-beta.0",
      "slot": 507761455
    },
    "value": [
      {
        "confirmationStatus": "finalized"
      }
    ]
  }
}
```

The confirmation status can be `finalized`, `confirmed`, or `processed`.
