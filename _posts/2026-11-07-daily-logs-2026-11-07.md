**Active Directory (AD)** is a directory service that centrally manages users, computers, groups, and information used to control access to resources. Its database is stored on servers called **domain controllers**. Each user, computer, and group is represented as an **object** in the directory.

**OU (Organizational Unit):** A container that organizes directory objects, such as users and computers. OUs help administrators apply Group Policy and delegate administrative responsibilities. **Security groups**, on the other hand, are used to assign permissions—for example, access to shared folders.

**LDAP (Lightweight Directory Access Protocol):** A protocol used to query and update the directory. An LDAP **simple bind** can authenticate using a username and password; use TLS through LDAPS or StartTLS to protect those credentials in transit. LDAP can also authenticate using Kerberos.
