## Obsidian default template

First install Obsdian Default Template Plugin from [community](https://community.obsidian.md/plugins/default-template)

Modify the following file : `.obsidian/plugins/default-template/data.json`

```json 
{
  "defaultTemplate": "Templates/Default Note.md",
  "folderTemplates": {},
  "ignorePaths": []
}
```

and create a new file `Templates/Default Note.md`

```yaml
---
type: notes
date: "{{date:YYYY-MM-DD}}"
project: "<placeholder>"
status: "<placeholder>"
severity: critical
tags: []
---
```
