## Add a default format in new page in Obsidian

First install Obsdian Default Template Plugin from Community.

In the following file : `.obsidian/plugins/default-template/data.json`

```json 
{
  "defaultTemplate": "Templates/Default Note.md",
  "folderTemplates": {},
  "ignorePaths": []
}
```

and the file `Templates/Default Note.md` would look like

```yaml
---
type: notes
date: "{{date:YYYY-MM-DD}}"
project: "<placeholder>"
status: "<placeholder>"
severity: critical
tags: []
---
```
