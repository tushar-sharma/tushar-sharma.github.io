## Skills vs Prompt with LLM

For LLM all input text is broken down into tokens. LLM is token in and token out. LLM doesn't have special pathway to differentiate skills or prompt.

Prompt example : 

```
System prompt: You are super engineer

User prompt: Explain this code.
```

A simple skill would look like 

```
Skills
---
you are super engineer 

FIrst you should understand code 

you have additonaltools to read system docs. 
```

So skills is prompt + workflow + any tools additional that it can have access. 

Are newer LLMs trained to follow skills differently?

## Lazy annoation with Webclient 

Les say you have a code

```java
public class DocumentRepository(@Lazy WebClient webClient) {

}
```

How's this differnet than 


```java
public class DocumentRepository(WebClient webClient) {

}
```

When you add `lazy` to something, Spring boot adds a lazy proxy object inplace of real object. And Dependency Injection is managed by Spring. but for lazy, it waits till the app actually needs it like when the method is actually invoked.

But why use lazy at all? Expensive bean creation defer it or something that's rarely used.
